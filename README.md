# 🎮 Campus Party Quest System

Campus Party Quest System은 캠퍼스 환경에서 게임 플레이어를 매칭하기 위한  
**퀘스트 기반 파티 매칭 시스템** 개념 프로젝트입니다.

기존의 커뮤니티 게시판 방식의 파티 모집 대신,  
플레이어 매칭 과정을 **게임의 퀘스트 시스템처럼 구조화**하는 아이디어를 기반으로 설계했습니다.

사용자는 퀘스트를 생성하거나 참여할 수 있으며,  
시스템은 이를 기반으로 플레이어 매칭을 진행합니다.

이 프로젝트는 소프트웨어 공학 수업에서 진행한  
**Conceptualization 설계 프로젝트**입니다.

---

# 🎮 Campus Party Quest System

A conceptual project designed to match game players within a campus environment.

Instead of traditional community-based party recruitment,  
this system structures player matching as **quest-based interactions**.

Users can create or join party quests, and the system facilitates  
player matching based on these quest activities.

📌 This project was created as part of a **Software Engineering Conceptualization project**.
