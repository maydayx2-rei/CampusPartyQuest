# Campus Party Quest System

Campus Party Quest System은 캠퍼스 환경에서 게임 플레이어를 매칭하기 위한 간단한 개념 프로젝트입니다.

기존 커뮤니티 기반 파티 모집 방식 대신, 플레이어 매칭을 **퀘스트 형태로 구조화하는 시스템**을 구상했습니다.  
플레이어는 퀘스트를 생성하거나 참여할 수 있으며, 시스템은 이를 기반으로 매칭 결과를 제공합니다.

이 프로젝트는 소프트웨어 공학 수업에서 진행한 **Conceptualization 설계 프로젝트**입니다.
